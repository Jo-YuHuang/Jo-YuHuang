## Featured projects

### Autonomous embedded-systems buggy navigation
**Embedded C · PIC microcontroller · PWM · I²C · UART**

Designed and implemented an autonomous robotic buggy with motor control, RGB colour sensing, and navigation logic. The project included PWM-based motion control, calibrated sensor processing with ambient-light subtraction and normalisation, threshold-based classification, and UART logging for calibration. Developed collaboratively in a two-person team using GitHub and achieved top-tier performance in final testing.

[View the project repository →](https://github.com/ME3-HECM/final-project-djs)

### Energy-saving automatic outside light
**Embedded C · ADC · LDR · software clock**

Built an autonomous outdoor-lighting controller that detects sunrise and sunset from ambient light. Implemented averaged adaptive thresholds, hysteresis, a sun-synchronised software clock, drift correction, daylight-saving-time handling, and leap-year logic in a modular design.
